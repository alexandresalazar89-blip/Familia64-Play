# Mundo à Porta — HOME Web

Public browser playtest deployment for the **Milestone 1 HOME walk**.

Current published build: **Milestone 1 · real HOME snapshot**

The game source project remains private. This repository contains only deployment material for the explicitly approved compiled Web build.

Published runtime baseline:

- 142 OSM building footprints
- 2 OSM-derived building heights
- 140 heuristic 6 m building heights
- 69 road features / ~4818 m
- DGT OrtoSat 2023 ground imagery
- DGT COS2025 land cover
- flat terrain placeholder until DGT Lote 1 LiDAR/MDS becomes available

The original orthophoto, COS/OSM source files, private HOME configuration, family photos and source project are not committed here as source material.
